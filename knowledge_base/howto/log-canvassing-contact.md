# How to log a new canvassing contact

(Placeholder documentation for a fictional platform; not the real VoteCivic/SignalVote product.)

1. From the main menu, open **Field** and select **Canvassing**.
2. Click **Log Contact**.
3. Search for the voter by name or address and select them.
4. Choose the contact result (Supporter, Undecided, Opposed, Not Home, or Refused).
5. Add optional notes, such as issues the voter raised.
6. Click **Save**. The contact appears in the voter's history and in the Canvassing Log.
